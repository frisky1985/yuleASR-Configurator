需要决定的下一项：参数区多宽
1

稀疏行

每行高度 ~28px，三列（参数·值·单位）+ 行内状态色块；可读性好，屏幕利用率低

2

紧凑行

每行 ~20px，参数名左对齐、值可编辑、单位右对齐；DaVinci Classic 风格，密度高

3

栅格表

表头固定、支持列排序和批量编辑；适合批量改值的场景，但普通阅读重

需要决定的下一项：模块切换优先走哪
1

树优先

左侧树是唯一真源；顶栏只显示当前模块名，切模块靠树点击

2

标签页 + 树

顶部有 Basic / 通信 / 诊断 等标签页，树在当前标签内收窄；DaVinci 新 UI 倾向

3

透视 + 标签页

最左小条是透视（编辑/校验/生成），每个透视内再分模块标签；重但规整
